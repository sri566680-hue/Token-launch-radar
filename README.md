A token launch radar that ranks pre-token protocols by an implied value built from the DefiLlama snapshot's own figures — TVL, seven-day growth and time with no token — and shows a dashboard with the board, a detail view for each protocol and a farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
